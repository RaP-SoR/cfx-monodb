# cfx-mongodb v1.0.0-dev — First pre-release

> **Channel:** `dev` (unstable)  
> **Base version:** `1.0.0`  
> **Not for production** — use stable `v1.0.0` from `main` when available.

First downloadable build of **cfx-mongodb**: a TypeScript MongoDB wrapper for FiveM/RedM that exposes a safe, typed export API for other resources (e.g. CTFFramework).

---

## What is included

| Area | Details |
|------|---------|
| **Runtime** | FiveM Node **22** only (`node_version '22'`, `mongodb@7`) |
| **Exports** | CRUD + admin: `find`, `findAll`, `findById`, `insert`, `update`, `delete`, `count`, `getVersion`, `getQueryStats`, `health`, `config`, `ensureIndexes`, … |
| **Contract** | CTFFramework-compatible envelopes — `{ success, ... }`, never throws; `insertedId` always string |
| **Security** | Query validation blocks dangerous operators (`$where`, …); URI redaction in logs |
| **Performance** | Optional slow-query logging + ring buffer (`getQueryStats`) via ConVars |
| **Tests** | 89 unit tests (Vitest), manifest ↔ export contract sync |
| **Docs** | [API](https://github.com/RaP-SoR/cfx-mongodb/blob/dev/docs/API.md), [Configuration](https://github.com/RaP-SoR/cfx-mongodb/blob/dev/docs/CONFIGURATION.md), examples |

---

## Install (from this ZIP)

1. Extract to `resources/cfx-mongodb` (folder name must match).
2. Set MongoDB ConVars — see [CONFIGURATION.md](https://github.com/RaP-SoR/cfx-mongodb/blob/dev/docs/CONFIGURATION.md).
3. In `server.cfg`: `ensure cfx-mongodb` **before** consumer resources.
4. Wait for `cfx-mongodb:ready` before calling exports from other resources.
5. Read `BUILD_INFO.txt` inside the ZIP for branch, commit, and channel.

**No local `yarn build` required** — `dist/` and production `node_modules/mongodb` are bundled.

---

## Minimum ConVars (dev server example)

```cfg
set mongodb_env dev
set mongodb_dev_url "mongodb://127.0.0.1:27017"
set mongodb_database "fivem_dev"
ensure cfx-mongodb
```

See profile templates: `docs/examples/config/` in the repo.

---

## Version string at runtime

```lua
local v = exports['cfx-mongodb']:getVersion()
-- dev builds: "1.0.0-dev+<commit>" or "1.0.0-dev"
-- stable builds (from main): "1.0.0"
```

Treat any version containing `-dev` as **unstable**.

---

## Upgrade path to stable

1. Development continues on **`dev`** → pre-releases `v1.0.0-dev`, `v1.0.1-dev`, …
2. When ready: merge **`dev` → `main`**
3. Tag **`v1.0.0`** on `main` → CI publishes a **stable** GitHub Release (no `-dev` suffix, not marked pre-release)
