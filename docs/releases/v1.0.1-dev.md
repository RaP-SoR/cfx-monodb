# cfx-mongodb v1.0.1-dev — Documentation & security patch

> **Channel:** `dev` (unstable pre-release)  
> **Base version:** `1.0.1`

## What is included (runtime)

Same export API as v1.0.0 — no new `server_exports`. See [API.md](https://github.com/RaP-SoR/cfx-mongodb/blob/dev/docs/API.md).

| Area | Details |
|------|---------|
| **Runtime** | FiveM Node **22** only (`node_version '22'`, `mongodb@7`) |
| **Exports** | CRUD + admin: `find`, `findAll`, `findById`, `insert`, `update`, `delete`, `count`, `getVersion`, `getQueryStats`, `health`, `config`, `ensureIndexes`, … |
| **Contract** | `{ success, ... }` envelopes — never throws; `insertedId` always string |
| **Security** | Query + **insert** validation blocks dangerous operators |
| **Tests** | 130 unit tests + integration tests (CI) |

## Install (from this ZIP)

1. Extract to `resources/cfx-mongodb` (folder name must match).
2. Set MongoDB ConVars — see [CONFIGURATION.md](https://github.com/RaP-SoR/cfx-mongodb/blob/dev/docs/CONFIGURATION.md).
3. In `server.cfg`: `ensure cfx-mongodb` **before** consumer resources.
4. Wait for `cfx-mongodb:ready` before calling exports.
5. Read `BUILD_INFO.txt` inside the ZIP for branch, commit, and channel.

**No local `yarn build` required** — `dist/` and production `node_modules/mongodb` are bundled.

## Optional: npm types package (same Release)

Each Release also ships **`cfx-mongodb-v1.0.1-dev.tgz`** — TypeScript types only.

```bash
yarn add cfx-mongodb@https://github.com/RaP-SoR/cfx-mongodb/releases/download/v1.0.1-dev/cfx-mongodb-v1.0.1-dev.tgz
```

```typescript
import type { CfxMongoInsertResult } from "cfx-mongodb/types";
```

Pin the same tag as the server ZIP.

## Upgrade from v1.0.0-dev or v1.0.0

- Drop-in replacement for export callers — same function signatures
- **`insert`** now rejects documents containing forbidden `$operator` keys (aligns with filter/update validation)
- Example docs moved to `docs/examples/lua/` and `docs/examples/typescript/` (root stubs removed)

Full list: [CHANGELOG.md — 1.0.1](https://github.com/RaP-SoR/cfx-mongodb/blob/dev/docs/CHANGELOG.md#101--examples-security-integration-2026-05-27)

## Version string at runtime

```lua
local v = exports['cfx-mongodb']:getVersion()
-- dev builds: "1.0.1-dev+<commit>" or manifest "1.0.1" on tagged dev ZIP
-- stable (from main): "1.0.0" until v1.0.1 merges to main
```

Treat any version containing `-dev` in BUILD_INFO as **unstable**.
